# Todos Api

## Primeros pasos

Crear el entorno virtual:

```bash
py -m venv .venv
```

Activar el entorno (elige según tu shell):

```bash
source .venv/bin/activate
```

Actualizar pip e instalar dependencias:

```bash
py -m pip install --upgrade pip
pip install -r requirements.txt
```

## Iniciar el proyecto
```bash
cd src
fastapi dev main.py
```
